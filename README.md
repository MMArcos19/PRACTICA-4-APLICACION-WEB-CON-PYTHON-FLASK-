# Cine Marcos 🎬

## Tecnologías utilizadas

- **Python:** utilizado junto con Flask para iniciar y gestionar el servidor web
- **HTML:** utilizado para crear la estructura de las páginas
- **CSS:** utilizado para diseñar la apariencia de la web
- **GitHub:** utilizado para guardar y entregar el proyecto


## Organización del proyecto

- `app.py`: archivo principal de Python y Flask
- `index.html`: página principal
- `peliculas.html`: catálogo de películas
- `registro.html`: formulario de registro
- `login.html`: inicio de sesión
- `reservas.html`: apartado de reservas
- `css/`: contiene los estilos de la página
- `img/`: contiene las imágenes de las películas
- `script.js`: contiene las funciones de JavaScript

## Ejecución

Para iniciar el proyecto hay que instalar Flask:

`pip install flask`

Después, ejecutar:

`python app.py`

Finalmente, abrir en el navegador:

`http://127.0.0.1:5000`
